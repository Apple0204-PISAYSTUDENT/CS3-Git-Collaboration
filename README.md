## Project Description
A simple command line Python greeting application created as a collaborative Git 

## Instructions for running greet.py
Make sure Git is installed in your computer and restart VS code. Then open VS code without a folder and clone the Git repository in the welcome tab and click clone from Github before selecting your repository from the list or paste the repository's .git URL directly. Pick a folder on your computer where VS Code will save the files click Open when prompted, click "Yes, I trust the authors", and run your files using the terminal or Run button as usual
